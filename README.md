# Collaboration Demo Project

![Simple CI](https://github.com/arminedjlal-eng/collaboration-demo/actions/workflows/ci.yml/badge.svg)

A demo project for practicing the complete Git and GitHub collaboration workflow.

---

## Project Overview

This repository demonstrates:

- Structured repository layout
- Issue-driven development
- Feature branches
- Pull Requests linked to Issues
- Code Review with Request changes and Approve
- CI pipeline on every push and PR
- Squash and Merge
- Conflict resolution and rebase
- Conventional commit messages

---

## Repository Structure

- `README.md` - Project documentation
- `app.txt` - Main application file
- `.gitignore` - Ignored files
- `.github/workflows/ci.yml` - GitHub Actions CI workflow
- `scr/` - Screenshots of every step

---

## Getting Started

1. Clone the repository
2. Open app.txt
3. Follow the contribution workflow

---

## Contribution Workflow

1. Open an Issue
2. Create a branch
3. Commit using Conventional Commits
4. Push and open a Pull Request
5. Request a Code Review
6. Wait for CI to pass
7. Squash and Merge

---

## Continuous Integration

The CI pipeline is defined in `.github/workflows/ci.yml`. It runs on every push and pull request.

---

## Screenshots

All steps are documented with screenshots in the `scr/` folder.
